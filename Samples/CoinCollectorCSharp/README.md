# Coin Collector (C#)

The Coin Collector game with scripts in C#. Same scenes/prefab/levels/UI as the C++ sample. The 5 scripts in `Assets/Scripts` replace the C++ module and declare no namespace (scene files use the type names `Coin`, `LevelDefinition`...).

## Running it

Open the folder from the Project Hub (**Add Existing...**). The editor compiles the scripts on first open. Until it has, `Main.scene` reports its `MainMenu` row as an unloaded type.
